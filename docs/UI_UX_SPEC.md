# 好美里防風林植物數位導覽 — UI／UX 規格 v1.0

## 定位與範圍
此文件沿用植物資料契約 v1.0，採用 JSON `order` 手動排序、僅公開 published、`isDemo` 示範警示、所有資訊卡直接展開、單張本地照片、手機優先、電腦單欄、無動畫。
本規格源自獨立 HTML/CSS UI 預覽；本專案的正式實作位於 Astro 元件與原生 CSS。

## 路由
- 根網址 `/haomeili-plant-guide/`：直接顯示純文字植物清單。
- `/haomeili-plant-guide/plants/`：呈現相同清單；共享 PlantList 元件與 published 資料，不是重新導向。
- `/haomeili-plant-guide/plants/[slug]/`：單一植物資料頁。
- 無效 slug 不生成路由；沿用 GitHub Pages 預設 404。
- 所有站內路徑經 `import.meta.env.BASE_URL`（或安全的路徑 helper）處理。

## 設計 Token
- 主色：`#287C60`；淡綠：`#DDEFE5`；白：`#FFFFFF`；淡灰：`#E9ECEB`。
- 文字使用深綠黑 `#183B2E`；次要字 `#496157`；外層背景 `#F4F8F3`。頁首使用森林綠 `#174C3A`，頁尾使用淡綠 `#DDEFE5`，卡片邊線使用 `#CFDED3`；示範警語使用暖沙色 `#FAF0DA` 與深褐字色 `#634A2B`。
- 文字：系統無襯線（system-ui, Noto Sans TC fallback），正文 16–17px，行高 1.75–1.85。主標 26px（窄手機）至 34px（桌面），卡片標題 19px。
- 容器：手機左右留 14–16px；最大寬度 760px、桌面置中單欄。
- 間距：標準 8 / 12 / 16 / 20 / 24 / 32px；卡片內距 16–20px；卡片圓角 12px；無陰影、無動畫。
- 文字連結須保有底線；焦點要有清楚的外框。鍵盤可使用所有導覽連結。

## 清單頁
- 全站 Header：左側網站名稱連回根目錄；右側 `所有植物` 連至 `/plants/`。
- 顯示 `所有植物` 主標、簡短操作說明、純文字連結清單；示範植物在名稱旁標註「（示範）」，不顯示清單警語區塊。非照片卡片、無搜尋、無篩選。
- 清單按 published `order` 升冪排序；示範項目緊鄰名稱加 `(示範)`；不得輸出 draft。
- 清單項目有清晰分隔線及足夠點擊空間。
- 根目錄與 `/plants/` 的資料、排序、文字完全一致。

## 植物介紹頁
順序：Header → 植物名稱 → 斜體學名 →（如 isDemo）示範警示 → 單張照片 → 基本資料卡 → 外觀特徵卡 → 生長環境卡 → 生態功能卡 → 防風林角色卡 → 上一種／下一種導覽 → Footer。
基本資料卡：科別必顯；別名陣列非空才顯。照片下方若有 `image.credit` 可顯示來源。`sourceUrls` 為維護用資料，不預設公開。
其餘內容卡只在有非空值時呈現，沒有收合或展開控制。
照片完整等比呈現、寬度不超出容器；不得硬裁切重要植物特徵；維持 alt 可讀性。預覽內的灰色照片區只是 UI 佔位，不是最終照片。
上一種／下一種只計算已發布植物的 order。第一種無上一種、最後一種無下一種；不得產生空 href、無效可點擊控制。手機仍維持兩欄，但較長名稱須換行，不得溢出。

## 無資料與錯誤處理
- 首頁若完全沒有 published，顯示明確空狀態說明，不列出草稿。
- published 必填欄位驗證失敗要中止建置；draft 可不完整但不得產生頁面或照片公開輸出。
- 圖片缺失不可悄悄替換成未授權照片，也不能冒充已完成驗收。
- `isDemo` 警示不得在非示範資料頁顯示。

## 驗收
1. 以寬 375px/390px 手機、768px 平板、1280px 桌面檢查版面沒有橫向捲動。
2. 手機正文 16–17px；桌面仍為置中單欄，主內容不寬於 760px。
3. 根頁、/plants/ 名錄相同，並按 order 10/20/30 排序。
4. 介紹頁五張資訊卡在有資料時全部展開（基本資料 + 四段敘述）。
5. aliases、credit 等選填欄位空白時沒有空白標題、空白卡片。
6. 首尾導覽連結正確；沒有指向 draft 或不存在 slug 的連結。
7. `isDemo` 在清單與詳情頁都以「示範」標註；非實地確認警語顯示於詳情頁。
8. 鍵盤 Tab 與 Enter 可操作所有導覽連結；圖片有 alt、標題階層正確。
9. 正式 Astro 版所有連結與照片在 GitHub Pages base path 下正常。
10. 無使用前端 JS、額外動畫、框架 UI 套件。

## Codex 接手說明
以此規格為視覺依據；HTML 預覽用來確認樣式，不要直接把預覽假資料、灰色照片佔位或絕對路徑搬入正式 Astro 網站。請優先複用已設計的植物 JSON、Zod Schema、publishedPlants 與 getAdjacentPlants，並在編寫畫面前檢查現有工作目錄、保留既有檔案。
