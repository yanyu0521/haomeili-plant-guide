# 好美里防風林植物導覽 — UI／UX 規格

## 使用情境

手機優先的海岸植物導覽。讀者先從植物名錄或參考地圖挑選物種，再閱讀基本資料與四段介紹。視覺延續森林綠、葉色與暖紙白，版面採清楚的編輯層級，方便戶外閱讀。

## 路由

- `/haomeili-plant-guide/`：首頁引導區、地圖預覽與植物名錄。
- `/haomeili-plant-guide/plants/`：步道點位排序的植物名錄。
- `/haomeili-plant-guide/map/`：參考地圖與 15 個可點擊植物位置。
- `/haomeili-plant-guide/plants/[slug]/`：植物基本資料、圖示、四段介紹、地圖定位與資料來源。

## 設計方向

- 延續自然導覽感，以森林綠、灰綠、暖白與少量砂金色作為主色。
- 標題有鮮明層次，內文保持舒適行寬與易讀行高。
- 植物名錄使用圖示、名稱、簡介與地圖捷徑的單欄索引；不將每筆資料包成相同卡片。
- 地圖以來源底圖為背景，標記可鍵盤操作並直接連到植物頁；旁邊提供可掃讀的對照名錄。
- 個別植物頁以圖示為視覺焦點，資訊卡直接展開，另提供同一張位置地圖及來源連結。
- 所有頁面在站內連結、圖示與底圖使用 GitHub Pages base path。

## 資料提示

- 當前資料以公開植物資訊與參考地圖整理。
- 地圖標點只表示原圖位置，非 GPS 測量座標。
- 植物圖示不是實拍照片；「木麻黃（長枝）」暫列木麻黃屬，未確認種名。

## 響應式與無障礙

- 手機名錄以單欄呈現；地圖後方接植物名錄，方便觸控選擇。
- 桌面地圖與對照清單並列；植物頁文字主欄保持適合閱讀的寬度。
- 圖上標記須有名稱與點位編號的無障礙標籤，鍵盤 Tab 與 Enter 可操作。
- 文字對比符合 WCAG AA，焦點輪廓明確，支援減少動態效果設定。
- 圖示需有說明 alt；地圖來源、位置精度與外來種資訊應清楚呈現。
